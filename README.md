# Muhammad Huzaifa Khan | Cybersecurity Portfolio

A responsive static portfolio designed for GitHub Pages.

## Files
- `index.html` - portfolio content
- `style.css` - responsive styling
- `script.js` - small interactive/mobile-menu behavior

## Before publishing
1. Replace the GitHub and LinkedIn placeholder URLs.
2. Replace `your.email@example.com`.
3. Add your real certificate verification link/ID.
4. Add your CV as `assets/Huzaifa-CV.pdf` and optionally link it from `index.html`.
5. Add project repository links if available.

## GitHub Pages
For a personal site, create a repository named `<your-github-username>.github.io`, upload these files to the root, then go to Settings → Pages and select the `main` branch and `/ (root)` as the source.

The site will be available at:
`https://<your-github-username>.github.io/`
